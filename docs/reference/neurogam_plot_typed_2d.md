# Explicit plotting options for temporal-generalisation results

Explicit plotting options for temporal-generalisation results

## Usage

``` r
neurogam_plot_typed_2d(
  x,
  type,
  theme = theme_neurogam(),
  palette = "vik",
  midpoint = 0.5,
  axes_labels = c("Training time (s)", "Testing time (s)"),
  ...
)
```
