# Compute two-sample posterior probabilities

Compute two-sample posterior probabilities

## Usage

``` r
compute_two_sample_prob(
  post_draws,
  null_value,
  participant_clusters,
  n_post_samples,
  credible_interval,
  predictor_type,
  baseline_window = NULL,
  odds_mode = "directional_rope",
  rope = NULL
)
```
